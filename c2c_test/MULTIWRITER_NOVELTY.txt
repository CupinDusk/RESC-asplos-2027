CONTRAST WITH THE SELF-INVALIDATION FAMILY (primary sources, read this session):
  DeNovo (PACT'11, local PDF denovo-pact2011.pdf p.1,4): removes the sharer-list
  directory BUT "on a write, a core register itself at (i.e., inform) the shared
  L2 cache. The L2 data banks serve as the registry ... keeps the identity of an
  L1 that has the up-to-date data (registered state)." => DeNovo has a
  SINGLE-OWNER REGISTRATION AT THE LLC/home. RESC Path A has NO such L2
  registration — co-writer discovery is a bounded L1-to-L1 cluster probe; state
  is per-sector in the L1 line. RESC Path B's token is an L1<->L1 migration, also
  never registered at a home node.
  VIPS/VIPS-M (PACT'12, vips-pact2012.pdf p.1-4): truly directory-less BUT relies
  on write-through at WORD granularity so "there is only one writer per word at a
  time (otherwise there would be a data race)"; self-invalidate + flush L1 at
  every synchronization. Concurrent writers to one word in one epoch = a data
  race, outside its model.

(d) CONCURRENT-WRITER DEMONSTRATION + HONEST SCOPE
################################################################################
The chair said DROP "at most one LD per line per epoch". The evidence supports a
genuinely CONCURRENT multi-writer claim in ONE epoch, in two forms:

  DISJOINT-SECTOR (the clean, load-bearing case) — Path A above.
    8 same-cluster SMs concurrently write DIFFERENT words (sectors) of ONE 128B
    line within one cluster epoch (mw_reduce.cu FORM=1: each rank st.global.wb to
    my_acc[rank]; all 8 words share one registered 128B line). The merge fires
    (mw_merge_entries=64), installs CLUSTER_MW_MERGE on BOTH copies, tracks each
    writer's own sectors (per-sector OR mask), and the serve-path invariant
    (gpu-cache.cc:2825, :3284) FORBIDS a single-owner whole-line forward from a
    MW_MERGE line so the consumer reads the byte-accurate merge. Multiple writers,
    one line, one epoch, directoryless, bit-identical (checksum 341120,
    mismatches=0). Correctness (I1/I2, below) proves no lost/torn write.

  CLUSTER ATOMICS (concurrent same-address RMW) — Path B above.
    8 SMs concurrently atomicAdd the SAME word; a single migrating owner-token
    serialises them over one sm2sm hop each (upgradereq=56). Concurrent RMW to
    one line, one epoch, directoryless (one token, no sharer set), bit-identical
    (checksum 33216). Correctness (I3) proves serialisability / no lost update.

  HONEST SCOPE / what is NOT claimed:
    - Racing PLAIN writes to the SAME byte are a data race, UNDEFINED under the
      PTX scoped memory model (Lustig et al., ASPLOS'19). RESC does not order
      them and only guarantees it never returns a value outside the write-set.
      This is case (C) in multiwriter.dat and is stated, not "handled".
    - The stencil secondary kernel (mw_stencil) is structurally
      single-writer-per-line in this sim's residency model: merge NEVER fires
      (mw_merge_entries=0 on all 4 arms), bit-identical. Reported honestly as a
      correctness case, NOT a merge demonstration (see MW_RESULTS.txt).
    - Multi-writer is a CORRECTNESS/generality result (removes the "single-writer
      forwarding cache" cap), NOT a new speedup axis. Path A is ~2% faster than
      correct-global and 0 vs old-escape; Path B is +0.6% honest token overhead.
      The win axis stays occupancy + read-share legality elsewhere in the paper.

(f) PRECISE NOVELTY STATEMENT vs DeNovo / hLRC / VIPS (evidence per clause)
################################################################################
STATEMENT:
  "The self-invalidation family (DeNovo PACT'11, hLRC MICRO'16, VIPS/VIPS-M
  PACT'12) provides coherence for data-race-free execution in which, within a
  synchronization phase/epoch, each coherence unit has a single writer;
  concurrent conflicting writers to one unit in one phase are, by construction, a
  data race outside their model. RESC provides coherence for the multi-writer
  patterns that ONE cluster epoch legitimately admits — concurrent disjoint-
  sector writers to a single line, and concurrent cluster-scoped atomics to a
  single address — and does so DIRECTORYLESS: no sharer vector, no home-node/LLC
  owner registry, only per-line/per-sector L1 state plus a bounded intra-cluster
  probe over the SM-to-SM fabric."

  Clause 1 — "SI family assumes single-writer-per-phase under DRF":
    DeNovo: "data-race-freedom eliminates concurrent conflicting accesses and
      corresponding transient states" and coherence state is kept "at the
      granularity at which the program guarantees data race freedom" (PACT'11,
      denovo-pact2011.pdf p.4).
    VIPS-M: "there is only one writer per word at a time (otherwise there would
      be a data race)" (PACT'12, vips-pact2012.pdf p.4).
    hLRC: built on the heterogeneous-race-free (HRF) model; GPUs "forgo CPU-like
      coherence protocols where each write obtains ownership to enforce the
      single-writer/multiple reader invariant" and self-invalidate at sync
      (MICRO'16, hlrc-micro2016.pdf p.1).

  Clause 2 — "RESC handles concurrent writers one epoch admits": Path A
    (disjoint-sector, 8 concurrent writers to one line, mw_merge_entries=64,
    bit-identical) + Path B (concurrent atomics, upgradereq=56, bit-identical),
    both this session (b); correctness I1/I2/I3 + ablations (e).

  Clause 3 — "directoryless": Path A no owner/sharer structure at all, bounded
    L1<->L1 cluster probe (gpu-cache.cc:3470, shader.cc:5079), per-sector state
    in the L1 line (gpu-cache.h:555); Path B a single migrating owner-token, "No
    sharer set" (gpu-cache.cc:244), one sm2sm hop/handoff, never broadcast
    (gpu-cache.cc:3646-3667). Evidence (c).

  Clause 4 — "beyond DeNovo specifically": DeNovo removes the sharer directory
    but STILL registers a single owner at the LLC ("on a write, a core register
    itself at ... the shared L2 cache. The L2 data banks serve as the registry",
    PACT'11 p.4). RESC Path A performs NO home/L2 owner registration for the
    merge — co-writers are discovered by a region-scoped L1 probe and reconciled
    per-sector, and the value reaches L2 by ordinary write-through. This is the
    load-bearing distinction from DeNovo.

  This also discharges the author's standing "multi-writer must be evaluated"
  directive: multi-writer is BUILT, MEASURED (b), proved correct (e), and framed
  against the correct neighbors — not punted to global.
